## Context

Range designers and installers need to show a customer and a contractor how a driving range will work on their site, and how it will be built. Range Studio brings the site's terrain, bays, radars, nets and infrastructure into one model. It then runs simulated shots to check radar coverage before anything is installed.

## What I built

- **One site model, several views:** plan, profile, split and 3D views of the same geometry. The 3D view includes a flythrough.
- **Infrastructure drafting:** huts, power and fibre routes connected at both ends, posts on nets and walls, and radar poles. A Connections check reports which radars have power and data.
- **Terrain and surroundings:** public elevation data with its source and datum shown, buildings and trees from open map data, and photorealistic 3D tiles that can be fitted to the project's own ground.
- **Results:** quick and full simulations, a Pass/Fail coverage verdict, per-shot problems, a trajectory inspector, shot profiles, and PDF, spreadsheet and image reports.
- **Shared projects:** Microsoft sign-in, SharePoint and OneDrive folders, history and versions, so a team works from the same copy.
- **Delivery:** Azure Pipelines builds a notarized macOS app and a Windows installer. Range Studio ships both inside the support tool's beta and on its own.
- **Tutorial suite:** 13 sections, 87 lessons and 125 short captioned videos, about 45 minutes in all. I built tooling that drives the real web UI in headless Chrome over the DevTools protocol, then draws the window frame, cursor, callouts, captions and zoom. The same tooling builds a searchable guide site with an interactive guide to the window's controls.

## Design decisions

The React interface runs with a local Python service inside a desktop shell. Long-running simulation and terrain work stays out of the editing loop. Saved results carry their inputs and engine context, so a report can explain what produced it.

The radar simulation itself belongs to another team's shared engine. Only one adapter module may import it, and CI enforces that boundary. My work is the application around it: the domain model, editing, geospatial and 3D views, reporting, sharing and release.

Visual context and engineering inputs are kept separate. Photoreal tiles, buildings and trees help people understand a site, but they never quietly change the model that gets simulated.

## Where it stands

Range Studio is in internal beta. Version 0.1.16, released in November 2026, is used by internal testers on macOS and Windows. The web and Python code have about 4,600 and 9,000 automated tests. Some results are not yet validated: the reference shot sets are waiting on an engine-side update before the Pass rule can be checked against them.
