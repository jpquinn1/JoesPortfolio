# Everyday-tool illustrations

Google Sheets and Gmail silhouettes are from [Simple Icons](https://github.com/simple-icons/simple-icons), under CC0 (see `SIMPLE-ICONS-LICENSE.txt`). The local SVGs use a restrained single-color fill.

- https://github.com/simple-icons/simple-icons/blob/develop/icons/googlesheets.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/gmail.svg

Slack is from [Devicon](https://github.com/devicons/devicon/blob/master/icons/slack/slack-original.svg), under the MIT license already included as `LICENSE.txt`. The existing Grafana icon is also from Devicon.

The n8n symbol is the official pink SVG from [n8n's logo guidelines](https://guidelines.n8n.design/logo), downloaded on November 10, 2026. Its original shape, aspect ratio, and color are preserved. The symbol is used with a visible n8n name in compact illustrative workflow nodes.

- https://guidelines.n8n.design/downloads/logo/symbol/n8n-symbol-accent.svg

Excel is identified by its text name alongside the Studio's own generic spreadsheet glyph, rather than a copied Microsoft app icon. Tool marks identify illustrative integration endpoints, not clients, endorsements, or partnership status.
